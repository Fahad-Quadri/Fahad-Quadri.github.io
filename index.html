// featured build

An enterprise network in a box

A virtualized lab built from scratch in VirtualBox: pfSense perimeter, Kali attacker, a domain-joined Linux client, and a Windows Server 2025 domain controller. Every step and failure is documented with screenshots.

// what broke & how I fixed it
  • VM wouldn't boot: "CPU doesn't support long mode"Windows VBS / Memory Integrity was holding VT-x. Disabled Core Isolation and verified with msinfo32.
  • Suricata crashed on start: ipfw divert-socket errorTested 4 independent start paths, edited config.xml directly, and root-caused it to the VirtualBox virtual NIC. Closed as a documented limitation.
  • realm discover found no realmTraced it to systemd-resolved's handling of .local; pointed the resolver at the DC directly.
  • Kerberos "Preauthentication failed" on domain joinA credential problem, not a network one: a special character mapped differently across keyboard layouts.
  • Hardened the domainGPO-backed password policy (min length 10, complexity, 90-day max age), verified with Get-ADDefaultDomainPasswordPolicy.

Featured Project

Home Lab — Network Security Monitoring

View on GitHub →

A virtualized network security lab built from scratch to practice router/firewall configuration, network segmentation, offensive scanning, and intrusion detection — built as hands-on study material alongside CompTIA Security+ prep.

Architecture

  • pfSense CE 2.7.2 configured as router/firewall — WAN via NAT, LAN on an isolated VirtualBox internal network
  • Ubuntu Server client VM on the same LAN, DHCP-leased from pfSense
  • Verified end-to-end internet routing (0% packet loss on outbound ping tests)

Firewall Rule Engineering

  • Wrote and deployed a custom LAN firewall rule to block ICMP traffic
  • Validated enforcement with a failed-ping test against the rule

Offensive Testing

  • Added a Kali Linux VM to the lab network
  • Ran Nmap host discovery and service scans against lab systems and documented findings

Intrusion Detection

  • Deployed Suricata IDS on pfSense via shell install after a GUI package-manager failure
  • Diagnosed a persistent inline/IPS divert-socket crash across four independent start methods, isolating it to a VirtualBox virtual NIC incompatibility
  • Closed out as a documented environment limitation with a clear root-cause writeup, rather than forcing an indefinite fix

Active Directory & Identity Management

  • Built a Windows Server 2025 Active Directory domain controller from scratch, promoting a new forest (fahadlab.local)
  • Joined a Linux client to the domain via realmd/SSSD, resolving a DNS resolver quirk and a Kerberos preauthentication failure
  • Configured Group Policy (domain password policy) and verified end-to-end AD/Linux identity integration
